來源：使用者提供的中文 SEO 課程（2024 年 6 月錄製，90 單元）。
2026-08-28 讀完 87 個單元（3 個字幕檔損毀），在此整理成可執行的方法。

這份是「怎麼做」的方法論（相對穩定）。兩者衝突時，以 `google-facts.md` 為準——

## 一、最核心的三個概念

### 1. 流量公式

```
某關鍵字的自然流量 = 該關鍵字的月搜尋量 × 該排名的點閱率
```

推論（這些推論才是重點）：
- **搜尋量 0 的關鍵字，排第一名也是 0 流量。** 不要猜搜尋量，用工具查。
- **排名掉出前 20 名，點閱率趨近 0。** 第 21 名和第 100 名沒有差別。
- 一個網站的流量 = 所有網頁流量的總和 = 所有關鍵字流量的總和。
  流量成長 = 有排名的關鍵字變多。
- **文章是取得關鍵字排名的最小執行單位**——不寫內容、不改網頁，就不會有成效。

### 2. 生財邏輯

「會搜尋 ○○ 的人，有沒有機會跟我買 ×××？」句子成立，這個關鍵字才值得做。

重合度分高／中／低／零。重合度零的關鍵字，就算做到第一名也賺不到錢。

**保家佳的例子**：
- 高：保單健診、醫療險怎麼買、保險規劃
- 中：勞保給付、健保自費項目
- 低：投資理財、房貸試算
- 零：程式教學（就算流量再高也沒用）

### 3. 一個蘿蔔一個坑

一個目標關鍵字 ↔ 一篇文章。**不要一篇文章想吃多個關鍵字，也不要多篇文章打同一個關鍵字。**

原因是**內部競爭**：一個網域在一個關鍵字上通常只會出現一個網頁。
你寫 50 篇談同一件事，Google 也只會派最強的那一篇上場，其餘 49 篇在該關鍵字上毫無貢獻。

## 二、關鍵字地圖（最重要的產出）

這是課程認為價值最高的東西，也是多數網站缺的。它把「規劃」變成「可執行的待辦清單」。

七個步驟（口訣：找 → 查 → 整 → 選）：

| 步驟 | 做什麼 |
|---|---|
| 1. 找 | 大量蒐集關鍵字，**這階段不要篩**。用「線頭」擴散：一個主詞丟進工具，拉出一整串 |
| 2. 查 | 用 Google Ads 關鍵字規劃工具查搜尋量。**不要問 AI 猜搜尋量**（實測灌水 10 倍以上） |
| 3. 整 | 剔除搜尋量 0 與沒有生財邏輯的字；依主題分類 |
| 4. 查排名 | 查每個關鍵字目前的排名與對應網址（超過 30 名一律記 100） |
| 5. 選字 | 勾選這次要做的目標關鍵字。**勾了就代表要執行**，新手一次勾 5–15 個就好 |
| 6. 決定做法 | 排名 30 名內 → 編輯既有頁面；30 名外或沒有相關內容 → 開新頁 |
| 7. 搜尋意圖 | 把目標關鍵字轉成文章標題；搜尋意圖相同的關鍵字併成同一組（一篇文章可吃多個字） |

沒有這張表，你不知道「還有哪些字沒拿到」——**Search Console 只顯示已經有曝光的字，
拿不到的字它不會告訴你**。這是關鍵字地圖無法被 Search Console 取代的原因。

字的分類（依搜尋量，非字長）：
- **大字／短尾字**：搜尋量最高、競爭最激烈、搜尋意圖模糊。新手避開
- **中尾字**：搜尋量夠、競爭適中、意圖清楚。**新手從這裡開始**
- **長尾字**（月搜 < 200）：競爭低、意圖最明確。不值得單獨開一篇，搭配中尾字一起寫

## 三、搜尋意圖：怎麼判斷、怎麼滿足

**核心方法：不要憑字面猜，去看該關鍵字目前的前 3–5 名，逆推 Google 認定的正確答案。**

前幾名共同討論了哪些子主題，那些就是「考題」。記錄題目，答案自己原創。

### 六種常見的意圖模板

| 模板 | 該給什麼 | 保家佳的對應 |
|---|---|---|
| **問題資訊型** | 一篇文章回答問題 | 「醫療險是什麼」「實支實付怎麼看」← 主力 |
| **策展排名型** | 列點推薦，通常要 10 個以上 | 「保險公司推薦」（保經立場不好寫，慎選） |
| **產品分類型** | 產品分類頁，品項要夠多 | 保險業較不適用 |
| **單一產品型** | 單一產品／服務頁 | 各服務子頁（保單健診、退休規劃…） |
| **首頁權威型** | 靠整站權威度，幾乎無法操作 | 「保險經紀人」這類大字，別強求 |
| **特殊功能型** | 要有工具／表格／試算 | **保費試算、需求分析問卷 ← 這是強項** |

判斷方式：搜尋該關鍵字，看前幾名給的是文章、列表、產品頁還是計算機。
給錯類型就排不上去——「內容寫得好」不能取代「給錯東西」。

**一個關鍵字可能有多種意圖並存**（例如同時出現推薦文與介紹文）。
挑一種做，不要一篇文章混著做。

## 四、寫作方法

### SEO 文章 ≠ 社群文章

| | SEO | 社群 |
|---|---|---|
| 誰找誰 | 讀者帶著問題來找你 | 你去吸引讀者 |
| 靠什麼贏 | **研究深度** | 情緒、共鳴、文筆 |
| 標題 | 直白帶關鍵字 | 有梗、有懸念 |

**這對非寫作專業的人是好消息**：SEO 內容不需要文采，需要的是願意做研究。

### 產大綱的四個工具

1. **九宮格**：中間放目標關鍵字，周圍八格填聯想到的子題，再把每格轉成小標
2. **內外觀點**：內＝你的親身經驗與立場（差異化來源、E-E-A-T 的 Experience）；
   外＝統計數據、研究、報告、書籍（專業度來源）
3. **常用句式**：「○○是什麼」「○○為什麼重要」「○○要怎麼做，方法 1 2 3」
4. **相關搜尋／相關問題**：Google 搜尋結果頁下方那些問題，直接拿來當子標題

### 五種文章模板

資訊解答型、資訊解答型2（是什麼→為什麼重要→好處→怎麼做）、
推薦列表型、流程步驟型、好處列點型。
**套不進去就不要硬套**，以搜尋意圖為準。

### 白話好懂的技巧

- 寫完唸出來，唸起來尷尬就是寫得不好
- 多分段（手機上 3–4 行一段，不超過 6 行）、多小標（2–5 段配一個小標）
- 「換句話說」「白話來說」：在專有名詞後面補一句，可讀性大幅提升
- 用比喻。想不到比喻可以請 AI 產，但要自己審過

### 置入品牌（別忘了做生意）

三種方式：內文插播（中間與結尾放 CTA）、客製插播（結合主題）、
內文鑲嵌（把自家服務當案例講解，最自然）。
**置入篇幅不要超過 10–20%**，否則會偏離搜尋意圖、影響排名。

## 五、On-Page：HTC 法則

**Title > Content > Header**，這三個是放目標關鍵字的重點部位。

- **Title**：目標關鍵字盡量往前放、出現 1–2 次、用完全比對（一字不差）、注意長度（看 pixel 不是字數）
- **Content**：第一段就進入重點並帶到目標關鍵字 2–3 次；不要在第一段置入品牌訊息（會偏題）
- **Header**：一頁只有一個 h1；h2/h3 條件允許時帶關鍵字，帶不上就算了

**Description 與 Keywords 幾乎無效**（Keywords 完全無效，見 `google-facts.md` 第 8 節）。
Description 寫不寫都可以，Google 常自行改寫。

其他次要項目：圖片壓縮（最重要）、alt（影響 <1%）、網址結構、內外部連結。

### 網址規則（開站第一天就要定，之後改動等於重來）

- 不要用中文（分享出去變亂碼，也不能用網址搜尋檢查索引）
- **絕對不要用日期當網址**（第二年就後悔）
- 小寫英文、用連字號 `-` 不用底線 `_`、層數越少越好
- **設一個前綴分類**（如 `/blog/`、`/services/`）——之後在 Search Console
  和廣告再行銷都能靠前綴一次篩出整類頁面

## 六、技術面：三階段瓶頸診斷

搜尋引擎三階段：**爬取 → 索引 → 排名**。任何 SEO 問題都先定位在哪一階段。

診斷順序：
1. **能不能被爬取**？robots.txt 有沒有誤擋、WordPress「搜尋引擎可見度」有沒有被勾
2. **有沒有被索引**？搜尋完整網址、搜尋文章標題、搜尋文章內文——
   **三種都要能找到才算「健康索引」**。只有網址搜得到、標題和內文搜不到，
   代表內文沒進資料庫，拿不到段落排名
3. **排名好不好**？到這一步才談內容與競爭

**判斷是不是瓶頸的標準**：把它修好，成效會不會提升？
會 → 是瓶頸，值得做。不會 → 不是瓶頸，別浪費時間。
（例：網站已被正常索引，那補 sitemap 對排名沒幫助——sitemap 是解決爬取／索引的。）

### 爬取預算

只有這幾種網站需要管理：超過 100 萬頁、或 1 萬頁且每天更新、
或 Search Console 出現大量「已找到但目前尚未建立索引」。
**一般中小型網站不需要管。**

### 索引報表最該緊張的五個狀態

伺服器錯誤 5XX、遭 robots.txt 封鎖、noindex、
**已檢索但目前尚未建立索引**（＝Google 認為不值得收錄）、
**已找到但目前尚未建立索引**（＝爬取預算不足）。

其餘多數狀態（替代頁面、重複網頁、頁面會重新導向）通常不是問題。

### 網站搬家／改版（最容易一次毀掉所有成果）

- 網址差一個符號就是不同網址，權重歸零
- 一定要用 **301**（永久轉址），不是 302、不是 307
- 理想是一對一對應（A→A′、B→B′），不是全部導到首頁
- 上線前用測試站驗證轉址、上線後前後幾天密集監測
- 先列出「涵蓋 80% 流量的網址清單」與「重要關鍵字清單」當救命稻草
- 就算做得完美，流量仍會損失 20–60%。**能不搬就不搬**

## 七、覆盤與再優化

SEO 的 O 是 Optimization——第一次做完只是開始。

網站優化三階段：醞釀期（3–6 個月，最沒有回饋感）→ 爆發期 → **衰退期（約 8–12 個月後）**。
「第二年才是戰鬥的開始」。

### 單頁分析流程

1. Search Console → 頁 → 輸入該網址 → 設定兩個等長的比較期間（自訂日期，不要用預設值）
2. 匯出 → 計算 Δ 點擊、Δ 曝光、Δ 排名（排名用「後期 − 前期」，正數＝進步）
3. 沒有排名的補成 100 名（Search Console 顯示 0 會讓計算失真）
4. 解讀三個指標的組合：

| 點擊 | 曝光 | 排名 | 解讀 |
|---|---|---|---|
| ↑ | ↑ | 不變 | **市場搜尋量變多**，不是你的功勞，也不可控 |
| ↑ | ↑ | ↑ | **你的優化有效**，繼續 |
| ↓ | ↓ | ↓ 超過 4 名 | **排名掉了**，這是你能救的，優先處理 |
| ↓ | ↓ | 不變 | 市場需求下降，不可控，別浪費力氣 |

### 全站分析

分析網站要**從網頁出發，不要從關鍵字出發**——前 20 名網頁通常佔 80% 流量，
但前 100 個關鍵字只佔 30%。

計算每個網頁的 Δ點擊 ÷ 全站Δ點擊 = 該頁的影響力%，
找出影響力最大的幾頁，再回到單頁流程處理。

**排名這個指標只用在關鍵字上，不要用在網頁或全站**——網頁的平均排名反映不了流量變化。

## 八、判斷 SEO 資訊真假的框架

看到任何 SEO 新聞、演算法更新、優化建議，問三個問題：

1. **What**：這在講什麼？先弄懂定義
2. **True**：這是真的嗎？官方有說嗎？多個獨立來源有說嗎？
3. **So What**：所以我要做什麼？

**如果得不到明確的行動方案或判斷準則，這則資訊對你就沒有價值，可以略過。**

判斷一個優化方法值不值得做，問兩件事：
- 對使用者有好處嗎？
- 對搜尋引擎有好處嗎？

兩個都是 → 長期有效。兩個都不是 → 短期可能有效，長期會被淘汰甚至懲罰。

**看 Google 做了什麼，不要只看 Google 說了什麼。** 官方說法有立場，
有些規則「只能做不能說」（公開就會被玩壞）。信任度抓 80–90%，保留獨立思考。

### 5-9　如何評估關鍵字的競爭難度

**核心問句**：「這個 SERP 上，有沒有我能補上的洞？」

競爭度從兩個角度評估：

**A. 網域權重角度（DR）**

用 Ahrefs 的 SERP overview 看前 10 名的 DR 分佈。免費查自己 DR 的工具：
`ahrefs.com/website-authority-checker`

不建議做的訊號：
- **DR 落差太大：跟前幾名差超過 30 分**

台灣市場參考值（課程給的數字，非官方）：
- SERP 上的基本門檻約 DR 43，有 60 為佳
- 自己的網域建議至少累積到 DR 20~30

**但 DR 低不等於沒機會**：課程展示的實例中，DR 26 的網站排在一群 DR 87–89 之間，
DR 2 的網站也擠得進前 10。靠的是「單篇內容極強」與「網站在該主題的相關內容夠多」。

**B. 內容角度**

逐一看前 10 名，判斷三件事：內容品質、內容字數、關鍵字字數。
問自己：**我有沒有機會超越對方、給出更好的答案？**

不建議做的訊號：
- **內容追不上**：看完前幾名，覺得沒有機會持平或超越
- **內容新鮮度**：前幾名全是最近的新內容 → 代表這個字競爭正激烈

**實務做法**：搜尋目標關鍵字，前 10 名逐則打勾或打叉（我贏得過／贏不過）。
勾越多代表成功機率越高；全部打叉就換一個字。

**選字的兩大重點**：
- **意願**：你喜不喜歡這個字（生財邏輯）、搜尋量多寡
- **能力**：競爭度，也就是上面兩個角度的評估結果

**新手守則**：避開搜尋量最高的前兩個詞、避開競爭度過高的字詞。

### 11-5　如何獲得更多反向連結

**反向連結的四個重點**（不是數量，是這四件事）：

| | 說明 |
|---|---|

**最實用的取得方法：模仿競爭對手的反向連結策略**

用 Ahrefs → Site Explorer → Backlink profile 看競爭對手的反向連結是從哪裡來的，
逐一評估自己能不能也拿到同樣來源。課程展示的案例中，
一個保養品牌的連結來源是 Elle、Vogue、Mybest、harpersbazaar 等媒體。

課程的立場：**「SEO 的模仿遊戲」——一切都是透明的，你應該努力模仿競爭對手。
模仿是為了超越，而不是抄襲。當你成功時，也會變成被模仿的對象。**

**對保家佳的意義**：反向連結是小網站最難的一環，不要當成第一優先。
但「看競爭對手的連結來源」這個動作本身很便宜，值得做一次盤點，
至少知道台灣保險領域的內容都被哪些媒體引用。
