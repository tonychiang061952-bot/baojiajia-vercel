# 文章結構模板

## 動筆前：內容任務書

抄自課程知識庫 §12，每篇都要先填完。填不出第 3、7、9 項就代表還不能寫。

```
1. 主要需求（讀者會搜的那句話）：
2. 讀者是誰：
3. 讀者現在卡在哪裡（用他自己的話寫）：
4. 適合頁型：判斷型 / 觀念型 / 情境型
5. 看完應得到什麼答案：
6. 看完希望採取什麼行動：
7. 我方能提供的第一手經驗、案例或工具：
8. 必須引用的權威來源（法條、機構、年份）：
9. 風險與例外（這篇不能保證什麼）：
10. 作者與審閱者：
11. 更新觸發條件（哪件事發生就要回來改）：
```

## 文型 A：判斷型（3,000 字，8 個 h2）

用在：「這個情況賠不賠」「有這個體況能不能買」「這樣做會怎樣」。
語料中專業型網站的主力文型，26% 的小標是判斷句。

```
最後更新日期：YYYY 年 M 月

問題情境：（一句話把讀者的處境講出來，用他會搜的詞）
先說結論：（3–5 句。直接給方向，並點出真正的爭點在哪）

文章目錄

本文為「◯◯◯」系列文章之一。 ← 建立主題群

（開場 3–5 段）
  · 引語或反問
  · 區分兩件常被混為一談的事
  · 界定範圍：這篇不能取代什麼

## h2-1：最基本的那個問題？
   第 1–2 句給答案 → 展開理由
   ① 要確認的第一件事
   ② 要確認的第二件事
   ③ 要確認的第三件事
   本段重點
   ✓ ✓ ✓（三句，離開上下文也看得懂）

## h2-2 ～ h2-5：其餘判斷面向，同結構

## h2-6：為什麼同一件事會有不同結果？
   放案例。個案結果不能外推，明講。

## h2-7：都符合就代表沒問題嗎？
   反向檢查，列進階項目

## h2-8：結語 —— 這是篩查，不是保證
   重申界線 → 下一步該做什麼

延伸閱讀（3–5 條站內連結，錨文字寫目的不寫關鍵字）
CTA（先描述讀者的處境，再說要準備什麼、能得到什麼）

## 常見問題 Q&A
   8–10 題。每題 2–3 句答完。
   問題用讀者的口語寫，不要用專業術語當題目。
```

**字數配比：** 先說結論 5%、開場 8%、主體 65%、結語 5%、Q&A 17%。

## 文型 B：觀念型（1,500–2,500 字，5–6 個 h2）

用在：「保險怎麼規劃」「保額怎麼抓」「什麼時候該檢視保單」。
教一套可重複使用的判斷方法，不處理單一爭議。

```
（情境開場：讀者做過但做錯的事）
先說結論：這件事分成 N 步，順序不能顛倒，因為⋯⋯

## 第一步：⋯⋯（每步一個 h2）
   為什麼是這一步 → 怎麼做 → 做錯會怎樣

## 常見的三個誤解
   反駁迷思。語料中專業型 47% 有這段

## 什麼情況要重來一次
   更新觸發條件

延伸閱讀 → CTA → Q&A（5–8 題）
```

---

## 文型 C：情境型（1,000 字，4 個 h2）

用在：擴散型主題、社群導流、新手教育。
語料中流量型網站的主力，字數中位數 1,018、h2 中位數 4。

```
（人物故事開場 2 段，200–300 字。給名字、給年齡處境、給一個具體的觸發事件）
（第 3 段把故事拉回主題：故事中的◯◯是很多人的寫照⋯⋯）

## 這件事是什麼？（一段講完，用比喻）
## 故事裡的◯◯遇到什麼問題？（把故事拆解成專業問題）
## 常見的 N 種狀況（列點，每點一小段）
## 那該怎麼辦（給下一步，不推銷）
```

**故事開場的三個要件**（缺一就假）：
具體的人物設定（家庭主婦、兩個孩子）、具體的觸發事件（大寶健檢尿蛋白異常）、
具體的心理活動（趕緊把報告放下，起身去找那位好久沒聯絡的業務員）。

---

## 三種文型怎麼選

| 讀者的狀態 | 文型 | 目標 |
|---|---|---|
| 已經出事，正在找答案 | A 判斷型 | 被引用、被信任 |
| 知道該做，不知道怎麼做 | B 觀念型 | 建立方法權威 |
| 還沒意識到有問題 | C 情境型 | 引起自覺、導流 |

一個主題群的理想配置：1 篇 B 當母文，3–5 篇 A 當子文互相連結，
2–3 篇 C 從社群或長尾字把人帶進來。
