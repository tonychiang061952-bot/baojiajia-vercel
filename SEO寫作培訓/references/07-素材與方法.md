### 為什麼沒有 letf.com.tw

該站 robots.txt 明文設定：

```
Content-Signal: search=yes, ai-train=no, use=reference
User-agent: ClaudeBot
Disallow: /
```

網站主人用機器可讀的方式聲明「不同意 AI 抓取與訓練」，我就不抓。
如果你自己讀了那個站、想把觀察轉述給我，我可以用你的筆記來補進教材——
那是你讀完之後的知識，跟我去抓站是兩回事。

## 排除規則（你 2026-09-04 指定）

排除商品比較、揭露商品名或公司名、純推薦書籍的文章。實作為：

- 命中 40 個保險公司／保經公司名之一 → 排除（實際排除 279 篇）
- 命中 2 個以上商品比較訊號（商品比較／保費試算表／CP值⋯⋯）→ 排除（1 篇）
- 命中 2 個以上書籍推薦訊號 → 排除（0 篇）

清單寫在 `工具/filter.py`，要加公司名直接改 `COMPANY`。

**排除規則本身就是寫作規則。** 排掉的不是「不好的文章」，是「會過期的文章」。
投保規則與費率有時效性，寫進去等於埋地雷；風格與判斷方法不會過期。

## 重跑步驟

語料原始 HTML 存在暫存區、不隨教材保留。要重新分析：

```bash
cd 工具
# 1. 取 sitemap（兩個站的 sitemap 網址見上表；smartbeb 的在 robots.txt 裡）
# 2. 抓取（自動快取，重跑不會重抓）
python3 fetch.py all_targets.txt
# 3. 抽內文 → corpus.jsonl
python3 extract.py
# 4. 套排除規則 → kept.json
python3 filter.py
# 5. 統計
python3 stats.py
python3 patterns.py
```

`語料/語料摘要.jsonl` 保留了 709 篇的網址、標題、字數與 h2 清單（**不含內文**），
要研究標題或大綱寫法可以直接用它，不必重抓。

## 什麼時候該重做

- 對標站改版或大量發新文（建議一年一次）
- 保家佳自己累積 20 篇以上文章後，把自己的文章也丟進同一套統計，
  跟對標站比對句長、問號密度、AI 套語，看差距在哪
