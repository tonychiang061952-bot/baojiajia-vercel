# SEO 寫作培訓包

**建立日期：** 2026-09-04
**用途：** 讓 AI 寫保險 SEO 文章時，有一套從實際語料量出來的標準可以遵守，
而不是憑印象寫出「很像 AI 寫的」文章。

## 這包東西是什麼

我把兩個對標網站的文章全部抓下來（989 篇），照你的規則排除掉商品比較、
有公司名商品名、純推書的文章，剩 **709 篇**做量化統計與精讀，
再把課程知識庫的 SEO 方法論接上去，變成一套可執行的寫作準則。

**白話比喻：** 這不是一本「寫作教學書」，是一份**體檢報告加上尺**。
報告告訴你寫得好的人實際上句子多長、多久問一個問題、多少比例的段落標題是問句；
尺讓你把自己的稿子量一量，看偏離多少。

## 檔案怎麼用

| 檔案 | 什麼時候看 |

| `SKILL.md` | **主準則。** 三條硬規則、語氣門檻、禁用詞、寫作流程 |
| `references/01-語料統計.md` | 想知道某個門檻憑什麼這樣定 |

| `references/04-句子與語氣手冊.md` | 稿子讀起來很硬、很 AI 的時候 |
| `references/05-交稿檢查表.md` | 發布前逐項檢查 |
| `references/06-範例拆解.md` | 想看好文章實際怎麼組裝 |

| `語料/語料摘要.jsonl` | 709 篇的標題與大綱（不含內文），研究標題用 |

## 兩個立刻能用的動作

**量一篇稿子：**

```bash
cd "~/Desktop/Claude 專案/baojiajia_insurance/SEO寫作培訓"
python3 工具/檢查稿件.py 你的稿件.md
```

**讓我以後寫文章自動照這套標準走：** 把整包複製成 skill 就行——

```bash
cp -R "SEO寫作培訓" "<你的網站專案>/.claude/skills/seo-writing"
```

之後我在那個專案寫保險文章時會自動叫用。技術面的 SEO（標籤、結構化資料、
sitemap）仍走既有的 `seo` skill，兩者分工不重疊。

## 這份教材的三個限制

1. **只學風格與結構，不學投保規則。** 商品規則與費率有時效性，
   刻意不寫進來，跟你之前定的知識庫原則一致。
2. **樣本偏一邊。** 630 篇來自流量型網站、79 篇來自專業型網站，
   但真正值得學的判斷型寫法幾乎都在那 79 篇。看 `06-範例拆解` 時要知道這件事。
3. **淺談保險觀念（letf.com.tw）沒納入。** 該站 robots.txt 明文拒絕 AI 抓取，
   我沒有去抓。原因寫在 `references/07`。
